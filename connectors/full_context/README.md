# Full-context connectors

**Status: parked.**

The fixed Pi and Prime Agent connectors must first prove the same public
candidate/evidence path. No full-context manifest, repository-adoption protocol,
or ambient agent-memory integration is implemented here.

A future reviewed version may bind a read-only repository snapshot, frozen
control-plane version, selected parent, ledger head, allowed paths, public task
context, omitted secret categories, and exact command contracts. It must not
expose protected evaluation material or let an agent rewrite Metering, select
itself, install a winner, or rely on mutable global state.
